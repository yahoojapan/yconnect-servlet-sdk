# Yahoo! ID連携 SDK for Java Servlet（Deprecated）
 
## 動作保証終了のお知らせ
Yahoo! ID連携 SDK for Java Servlet は2025/5/30をもって動作保証を終了いたしました。
 
SDK自体は引き続きご利用いただけますが、今後の弊社システムの変更などにより、一部機能が予告なくご利用いただけなくなる可能性がございますので、代替手段への移行をご検討ください。
 
### 詳細
詳細については下記のページをご覧ください。
* https://developer.yahoo.co.jp/changelog/2025-04-24-yconnect42.html
